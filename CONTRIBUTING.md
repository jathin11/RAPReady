# Contributing

Thank you for helping improve RAPReady.

1. Open an issue describing the problem, target SAP release, expected behavior, and proposed rule or change.
2. Create a focused branch and keep repository access behind `ZIF_RR_REPOSITORY`.
3. Add ABAP Unit tests for every decision path you add or change.
4. Run package activation, ABAP Unit, ATC, and an OData V4 smoke test in a compatible system.
5. Update the rule reference and release-sensitive compatibility notes.
6. Submit a pull request with screenshots only when they demonstrate a meaningful UI change.

By contributing, you agree that your contribution is licensed under Apache-2.0.
